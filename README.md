# Hemen Babis Portfolio

Personal website final project for `CS 463/563 - Intro to Web Development`.

## Project Overview

This is a one-page personal portfolio website built with:

- `HTML`
- `CSS`
- `JavaScript (ES6+)`

The site includes:

- A responsive navbar
- An About section
- A Previous Work section
- A Projects section
- A Contact form with JavaScript validation
- Scroll-based interactivity and reveal animations

## Run Locally

Because this is a static site, you can run it by opening `index.html` in a browser.

If you want to serve it locally from a terminal, you can run:

```bash
python3 -m http.server
```

Then open:

```text
http://localhost:8000
```

## File Structure

- `index.html` - site structure and content
- `styles.css` - full visual styling and responsive layout
- `script.js` - navbar behavior, scroll interactions, and form validation

## Outside Sources Used

- Google Fonts
  - `Instrument Serif`
  - `Manrope`

No premade website theme or premade Bootstrap theme was used.

## Deployment

Deploy this project with GitHub Pages or another static hosting provider.

GitHub Pages option:

1. Push the code to a public GitHub repository.
2. Go to `Settings -> Pages`.
3. Set the source branch to `main`.
4. Save the configuration.
